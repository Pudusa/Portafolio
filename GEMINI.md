# Portafolio Workspace Instructions

## Directory Overview
This repository serves as the workspace for the **Portafolio** project. It is structured as a general development and portfolio repository intended for housing portfolio websites, projects, showcases, or related professional artifacts.

## Structure & Contents
- `.idea/`: IntelliJ IDEA / WebStorm IDE configuration files (`workspace.xml`, `modules.xml`, `Portafolio.iml`).
- Root Directory: Designated for portfolio applications, web pages, documentation, and project assets as development proceeds.

## Development & Usage Guidelines
- **Project Type:** Personal Portfolio / Web Project workspace.
- **Conventions:** Follow clean code practices, maintain high visual aesthetics for portfolio pieces, and ensure proper documentation for any added projects or web pages.
- **Security & Secrets:** Never commit sensitive personal information, API keys, credentials, or `.env` files.
